# Student Information Card

A simple program that displays a student's profile, including name, major, graduation year, email, hometown, and favorite hobby. This project shows proper Git Workflow, version control, and formatting in Python.

## Features

- Display student name (original)
- Display major and graduation year (original)
- Display email (added)
- display hometown (added)
- display favorite hobby (added)
- Improved formatting with *40 headers, emojis, and \n spacing (added)
- Comments describing the program (added)

## Technologies Used

- Python 3.9
- Git for version control
- GitHub for repository hosting

## Installation and Setup

### Prerequisites
- Python 3.9 installed on your computer

### Steps to Run

1. git clone https://github.com/Jennijack89/CPSC4205_GitWorkflow_Fork_JenJackson.git
2. Go to the project directory: cd CPSC4205_GitWorkflow_Fork_JenJackson
2. Open Python and run the program python student_info.py

## Usage

Open the program in python and run it to see the formatted student information card.
